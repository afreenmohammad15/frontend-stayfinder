🏠 StayFinder – Hostel & PG Discovery Platform

StayFinder is a web-based platform designed to help students and working professionals discover hostels and Paying Guest (PG) accommodations easily. Users can explore accommodation options based on location, rent, amenities, ratings, and other preferences.

🚀 Project Overview

Finding suitable accommodation in a new city can be difficult. StayFinder aims to simplify this process by bringing accommodation listings and essential property information together in one convenient platform.

✨ Features

- 🏡 Browse hostel and PG accommodation listings
- 🔍 Search for properties by location
- 💰 Explore accommodation options based on rent
- 🛏️ View property details, rooms, and amenities
- ⭐ Display property ratings where available
- 📍 Support location-based property discovery
- 📱 Responsive user interface for different screen sizes
- 🔐 Optional login for users, depending on the enabled functionality

⚙️ Installation and Setup

Prerequisites

- Node.js and npm
- Java Development Kit (JDK) compatible with the backend project
- PostgreSQL
- Git

Run the Frontend

Clone the repository:

git clone https://github.com/afreenmohammad15/frontend-stayfinder.git

Navigate to the project folder:

cd frontend-stayfinder

Install dependencies:

npm install

Start the development server:

npm run dev

Open the local URL displayed in the terminal.

Run the Backend

Clone the backend repository:

git clone https://github.com/afreenmohammad15/stayfinder-backend.git

Open the backend project in your preferred Java IDE. Configure PostgreSQL and the required environment variables according to the project configuration, then run the Spring Boot application.

Ensure that the frontend API URL matches the backend server address.

🗄️ Database Configuration

StayFinder uses PostgreSQL for database storage.

Before running the backend:

1. Install and start PostgreSQL.
2. Create the required database.
3. Configure the database URL, username, and password using environment variables or your local configuration.
4. Start the backend and verify that database connectivity works.

Never commit real database passwords, API keys, or other secrets to GitHub.
